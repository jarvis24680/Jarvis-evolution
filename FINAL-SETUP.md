# JARVIS Final configuration

Capabilities:
- Claude primary AI
- Optional OpenAI second model
- Persistent memory and learning journal
- Image input path
- Browser speech recognition and speech output hooks
- Web-research ingestion endpoint
- Evolution lab with user notification
- Production code protected from automatic overwrite
- Capacitor Android packaging
- GitHub Actions cloud APK build

Server environment variables:
ANTHROPIC_API_KEY (required)
OPENAI_API_KEY (optional)
CLAUDE_MODEL (optional)
OPENAI_MODEL (optional)

Keep API keys server-side.

Voice: the browser's installed speech engine supplies the voice. The persona is configured as a distinct
cinematic assistant style rather than copying a particular actor's voice.
