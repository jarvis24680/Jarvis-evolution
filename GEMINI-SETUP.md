# JARVIS Gemini setup
Primary AI: Gemini.
Optional second model: OpenAI.
Required backend variable: GEMINI_API_KEY (Google also documents GOOGLE_API_KEY).
Optional: OPENAI_API_KEY, GEMINI_MODEL, OPENAI_MODEL.
Keep keys server-side.
Google documents Gemini OpenAI compatibility, image understanding and function calling, but this build calls Gemini directly.
